## 📌 What is React State?

**State** in React is a built-in object that stores property values that belong to the component. When the state changes, the component re-renders automatically to reflect the new data.

State is used to create dynamic and interactive components. Unlike props, which are passed from parent to child, state is managed **within** the component.

---

## 🔑 Key Features of State

* State is local and controlled within the component
* State is mutable and updated using the `setState` function (in class components) or `useState` hook (in function components)
* A state change triggers a re-render of the component

---

## 💡 Why Use State?

State allows components to respond to user input, server responses, or any other change in data over time. This helps in building interactive user interfaces, such as:

* Form inputs
* Button click counters
* Live-updating data displays

---

By understanding and using state effectively, developers can build powerful, data-driven components in React applications.
